## شرح مرحله

۱. صفحه آغازین جدید برای انتخاب بین «سامانه جامع املاک سلام» و «محاسبه‌گر مستقل» اضافه شد.
۲. هر دو محیط از صفحه آغازین در پنجره جداگانه باز می‌شوند.
۳. میزکار جامع نیز میانبر ورود به محاسبه‌گر مستقل دارد.
۴. ۱۵ بخش داشبورد با نمادهای متمایز نمایش داده می‌شوند.
۵. فایل‌های صفحه آغازین و میزکار در بسته ویندوز قرار گرفتند.
۶. گردش ساخت ویندوز با تغییر صفحات میزکار نیز اجراپذیر خواهد بود.
۷. برای پنجره‌های فرزند نیز فقط صفحات محلی مجاز پذیرفته می‌شوند.
